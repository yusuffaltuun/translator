# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it privately by emailing **yusuf@example.com** (replace with the actual maintainer email).

**Do not** open a public GitHub issue for security vulnerabilities.

Please include the following details in your report:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

You can expect an acknowledgement within 48 hours, and we will work to address validated vulnerabilities as quickly as possible.
